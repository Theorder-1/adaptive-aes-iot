# adaptive-aes-iot
 Adaptive AES for Energy-Efficient IoT and Embedded Systems

## Overview
Dynamic AES-128/192/256 selection based on battery, CPU, priority, and threat level.

## Hardware
- ESP32 DevKit V1 (80 MHz)
- MPU6050 (motion sensing)
- INA219 (energy measurement)

## Key Results
- 100% decryption success (500 packets)
- Avalanche effect: 50.12%
- Entropy: 7.218 bits/byte
- Energy savings: 1.15% vs fixed AES-256
